# Fitness Buddy App - Frontend 🏋️‍♂️

A premium, modern React application for tracking your fitness journey.
This is the Frontend repository for the **Fitness Buddy** Full Stack project.

## 🌟 Project Description
Fitness Buddy is designed to help users log, track, and manage their daily workouts. With a sleek dark mode UI, smooth animations, and an intuitive dashboard, users can easily monitor their progress over time.

## ✨ Features
- **User Authentication**: Secure Sign Up & Login (via Supabase Auth)
- **Dashboard**: View recent workouts and track total/weekly stats
- **Workout Management**: Log new workouts, edit existing entries, and delete workouts
- **Profile Management**: View active user status and securely log out across devices
- **Premium UI/UX**: Built with Tailwind CSS, featuring glassmorphism, glowing gradients, and responsive layouts
- **Dark Mode First**: Carefully crafted dark theme using Zinc and Emerald/Cyan color palettes

## 🛠️ Tech Stack Used
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Components & Icons**: ShadCN UI styling patterns, Lucide React
- **Routing**: React Router DOM (v7)
- **API Communication**: Axios (with interceptors for auth headers)
- **State Management**: React Context API
- **Deployment**: Netlify (Target)

## 🚀 Installation Steps
1. Clone the repository: `git clone <repository-url>`
2. Navigate to the frontend directory: `cd frontend`
3. Install dependencies: `npm install`
4. Set up environment variables based on `.env`:
   ```env
   VITE_API_URL=http://localhost:5000/api
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
5. Start the development server: `npm run dev`
