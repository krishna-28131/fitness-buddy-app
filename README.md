# Fitness Buddy App

A full-stack fitness tracking application built with React, Tailwind CSS, Shadcn UI on the frontend, and Node.js, Express, and Supabase on the backend.

## Links
- **GitHub Repository**: [https://github.com/krishna-28131/fitness-buddy-app](https://github.com/krishna-28131/fitness-buddy-app)

## Features
- Track daily workouts and exercises.
- User authentication via Supabase.
- Responsive modern UI design.
- RESTful API for managing fitness data.

See the `frontend` and `backend` directories for specific setup instructions for each part of the application.
